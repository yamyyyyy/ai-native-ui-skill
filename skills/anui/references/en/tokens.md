# Design tokens (ANUI Tokens)

> This file defines ANUI's own tokens: a monochrome OLED / high-contrast system plus one functional red.
> - Implementation: `demo/src/app.css`.
> - Design rationale: `monochrome.md`.
> - Contrast is checked by `scripts/contrast.py`; `npm run check` writes `reports/contrast.md`.

## 1. Themes and selectors

> **Default pairing (updated 2026-10-25):** light = `hc` (pure-white high contrast), dark = `oled` (pure black).
> - `oled-hc` is the optional OLED high-contrast theme.
> - `paper` / `white` / `dark` are optional variants.
>
> OLED is aligned with HC:
> - lines strengthened to `white / .14` (line) and `/ .24` (line-strong);
> - ink 0.97 / 0.82 / 0.72 / 0.60;
> - weights not reduced (400/500/600), tracking 0;
> - red `0.79 0.125 24`.
>
> `oled-hc` has:
> - ink 1.0;
> - lines `/ .5` (line) and `/ .8` (line-strong);
> - a 1px ring, no shadows, weights +50.
>
> Both high-contrast themes turn off frost and grain.

- `data-theme` has 6 values: `hc` (default light), `oled` (default dark), `oled-hc`, `paper`, `white`, `dark`.
  - With no stored choice, `demo/motion.js` picks one from `prefers-color-scheme` / `prefers-contrast`.
  - `?theme=` forces a theme.
- `dark` and `oled` also add `.dark` to html, for Tailwind's `dark:` variant.
- Any subtree can override locally with `class="dark"` or `data-theme="white"`. Derived variables are redeclared on `:root, .dark, [data-theme]`, so islands resolve correct values.

## 2. Differences from beautiful-ui

| Aspect | BUI | ANUI Mono |
|---|---|---|
| Themes | light / dark | 6: high contrast / OLED / OLED HC / paper / white / near-black, light and dark tuned separately |
| Grey hue | Cool blue-grey h≈248–286, with different C and H per token | One shared `--tint-c / --tint-h`: paper warm 85, near-black cool 265, the rest 0 |
| Accent | Blue `0.626 0.205 255` | **No hue**: `--accent = --ink`, emphasis by inversion; the only hue is `--red` |
| Green / orange / tag colours | Tags in 6 hues | Mapped to ink / ink-2; tags differ by fill / dashed / half fill / hatching |
| Lines | Solid `--line`, light 0.946, dark 0.308 | **Alpha**: light `ink / .085`, `/ .15`; dark `white / .075`, `/ .13`. Adapts to whichever layer it sits on |
| Dark elevation | surface 0.26 + shadow | page 0.165 → surface 0.212 → raised 0.245 → overlay 0.278, plus a 1px top highlight `--hi` |
| Text | Dark ink-3 is 0.541 (APCA about Lc 30) | Derived from APCA: dark ink 0.955, ink-2 0.80, ink-3 0.70; see `reports/contrast.md` (generated by `npm run check`) |
| Weights | Fixed | `--fw-*`: 20–40 lighter in dark (halation compensation), 50–100 heavier in high contrast |
| Selection / focus | Blue accent-tint / blue outline | Inverted selection; ink outline with a page-colour washer |
| Fonts | Inter + JetBrains Mono, system fonts for Chinese | Geist + Geist Mono + ANUI Sans SC (a Noto Sans SC subset, renamed per OFL) |
| Radii | card 10 / window 14 | card 12 / window 16 (chip 6 / control 8 unchanged) |
| Tooltip | Always dark | Inverted in light themes (ink background); overlay plus outline in dark themes |

## 5. Fonts, sizes and typography

- Families:
  - `Geist` (Latin);
  - `ANUI Sans SC` (Chinese; a Noto Sans SC subset renamed per OFL);
  - `Geist Mono` (code).

  All are variable fonts; the `wght` axis drives dark / high-contrast weight compensation. Fallbacks: `ui-sans-serif, system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`.
- Body:
  - `14px / var(--lh)` (1.55 light, 1.6 dark), `letter-spacing: var(--track)`;
  - `font-feature-settings: "kern" 1, "chws" 1`;
  - `text-spacing-trim: trim-start`, `text-autospace: normal`, `line-break: strict`.

  Chinese typography details are in monochrome.md §11.
- Headings use `text-wrap: balance` and paragraphs `text-wrap: pretty`; numbers always use `tabular-nums`.
- Weights come from `--fw-normal / --fw-medium / --fw-semibold` (Tailwind `font-*` is mapped):
  - high contrast / OLED: 400/500/600;
  - HC and OLED-HC: +50 to 100;
  - near-black: 380/470/560.
- **Size scale (≤ 4 steps, minimum 12px):**

| Token | Value | Line height | Use for |
| --- | --- | --- | --- |
| `--text-meta` | 12px | 16px | Meta, chips, timers, sources |
| `--text-body` | 13px | 18px (composer) / 1.625 (long text) | Body, row titles, inputs |
| `--text-title` | 14px | 20px | Card titles, tall composer input |
| `--text-display` | 20px | 28px | Page titles, KPI numbers (optional 4th step) |

## 6. Radii and spacing

- Radii: chip 6 / control 8 / card 12 / window 16 / pill 9999. Nesting must be concentric: `R_in = max(0, R_out − padding)` (craft-rules.md).
- Spacing:
  - card padding 12px;
  - row heights 24 (trace rows) / 28 (tool rows, buttons) / 36 (menu rows) / 44 (task rows);
  - gaps of 4 / 6 / 8 / 10 / 12.
- **Shadow clip margin.**
  - An e3 overlay (`--sh-3`: `0 24px 48px -12px`) extends 36px below and 12px above.
  - Inside `overflow:hidden` or a scroll container, leave that margin or switch to an inset outline; see craft-rules.md.

## Appendix A: beautiful-ui source values (historical reference, no longer the default)

> These values were read from `slev12397/beautiful-ui@44a274e` (MIT).
> - From v0.1 on, this skill no longer uses that blue-grey palette or the Inter font.
> - They are kept only for comparison, to make sense of the original sizes that appear in the component specs (components.md).
>
> Labels:
> - **[BUI]** original value;
> - **[DAU]** desktop-agent-ui rule;
> - **[merged]** how a conflict between the two was resolved;
> - **unverified** a value absent from the source and derived at the time.

### A.1 Conflict resolution summary

| Aspect | BUI original | DAU rule | Adopted by this skill |
| --- | --- | --- | --- |
| Font size | 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 17 / 20 px all in use | ≤4 sizes, minimum 12px | **12 / 13 / 14 + optional 20 (display)**. BUI 10.5–12.5 → 12; 13/13.5 → 13; 14 → 14; 17/20 → 20 [merged] |
| Lines | `0 0 0 1px var(--line)` solid ring | 0.5px hairline | **0.5px ring by default** (`--ring-w: 0.5px`), falling back to 1px at DPR<2 (so 1x screens don't round it to 0) [merged] |
| Shadows | shadow-card / shadow-btn on every card and button | Use sparingly: only overlays, windows, keys | **Keep BUI's shadow values** (visual layer), but only for cards (static card), buttons (btn) and overlays (raised/overlay); list rows, tables and inline blocks use hairlines only [merged] |
| Radii | chip 6 / control 8 / card 10 / window 14 / pill 999 | Nesting must be concentric, `R_in = max(0, R_out - padding)` | **Keep BUI's scale** and check nesting with the formula (e.g. card 10 + padding 4 → inner 6 = chip ✔; card 10 + pad 12 → inner 0–2) [merged] |
| Separators | No middle dots in copy (BUI itself mostly has none) | No "·" | No middle dots [DAU] |
| Left stripes | Left accent bar on CodeBlock diff rows | No left-stripe cards | A 2px row marker inside diff rows is allowed (it is a code gutter, not a card); **forbidden at card level** [merged] |

### A.3 Shadows

shadow-plugin (flornkm) provides smooth layered `--shadow-xs…lg`; BUI composes semantic shadows on top [BUI]:

```
light:
--shadow-hairline: 0 0 0 1px var(--line);
--shadow-btn:     0 0 0 1px var(--line-strong), var(--shadow-xs);
--shadow-card:    0 0 0 1px var(--line), var(--shadow-sm);
--shadow-raised:  0 0 0 1px var(--line), var(--shadow-md);
--shadow-overlay: 0 0 0 1px var(--line), var(--shadow-lg);
--shadow-inset-field: inset 0 1px 2px oklch(0 0 0 / 0.12);
dark (ring becomes low-opacity white, increasing with elevation):
--shadow-btn:     0 0 0 1px oklch(1 0 0/.10), 0 1px 2px oklch(0 0 0/.3);
--shadow-card:    0 0 0 1px oklch(1 0 0/.11), 0 1px 2px oklch(0 0 0/.2), 0 2px 6px oklch(0 0 0/.2);
--shadow-raised:  0 0 0 1px oklch(1 0 0/.13), 0 2px 10px oklch(0 0 0/.22);
--shadow-overlay: 0 0 0 1px oklch(1 0 0/.15), 0 8px 28px oklch(0 0 0/.34);
--shadow-inset-field: inset 0 1px 2px oklch(0 0 0/.4);
```

shadow-plugin's exact light `--shadow-xs…lg` layer values don't appear in the BUI repo (they come from the npm package). This appendix gives no derived values; run `npm i shadow-plugin` for the real ones (unverified).

**Clip margin:** the dark overlay extends 8 + 28 = 36px below and 28−8 = 20px above. Inside `overflow:hidden` or a scroll container, leave at least that margin; see craft-rules.md.
